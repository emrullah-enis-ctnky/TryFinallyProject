## Problem

`n` değerinden küçük pozitif asal sayıların adedini bulun. 0 ve 1 asal değildir.

## Örnekler

- `countPrimes(10)` → `4`
- `countPrimes(2)` → `0`

## Kısıtlamalar

- 0 <= n <= 1000000.

## İpucu

Bir asal bulunduğunda onun katlarını asal olmaktan çıkarın.
