## Problem

Ein Lager erfasst die Anzahl quadratischer Kisten als `count`. Schreibe `isPerfectSquare`, das prüft, ob diese Zahl das Quadrat einer ganzen Zahl ist. Negative Zahlen sind keine Quadratzahlen.

## Beispiele

- `isPerfectSquare(49)` → `true`
- `isPerfectSquare(50)` → `false`

## Einschränkungen

- `-2147483648 <= count <= 2147483647`

## Hinweis

Du kannst die möglichen Wurzeln in einem sortierten Bereich eingrenzen.

## Startcode

```cpp
class Solution {
public:
  bool isPerfectSquare(int count) { return false; }
};
```

```java
class Solution {
  public boolean isPerfectSquare(int count) { return false; }
```

```python
class Solution:

        return False
```
