## Problem

Bir depodaki kare kutuların toplam sayısı `count` olarak verilir. Sayının bir tam sayının karesi olup olmadığını belirleyen `isPerfectSquare` metodunu yazın. Negatif sayılar tam kare değildir.

## Örnekler

- `isPerfectSquare(49)` → `true`
- `isPerfectSquare(50)` → `false`

## Kısıtlamalar

- `-2147483648 <= count <= 2147483647`

## İpucu

Olası kök değerlerini sıralı bir aralıkta daraltabilirsiniz.

## Başlangıç Kodu

```cpp
class Solution {
public:
  bool isPerfectSquare(int count) { return false; }
};
```

```java
class Solution {
  public boolean isPerfectSquare(int count) { return false; }
}
```

```python
class Solution:
    def isPerfectSquare(self, count):
        return False
```
