## Problem

Negatif olmayan `n` sayısının karekökünün aşağı yuvarlanmış tam sayı değerini bulun.

## Örnekler

- `integerSquareRoot(16)` → `4`
- `integerSquareRoot(20)` → `4`

## Kısıtlamalar

- 0 <= n <= 2147483647.

## İpucu

Çarpımın taşmaması için orta değeri bölme sonucuyla karşılaştırın.
