## Problem

Bestimme, ob sich benachbarte Bits in der Binärdarstellung einer positiven Zahl unterscheiden.

## Beispiele

- `hasAlternatingBits(5)` → `true`
- `hasAlternatingBits(7)` → `false`

## Einschränkungen

- 1 <= n <= 2147483647.

## Hinweis

Schiebe die Zahl um ein Bit nach rechts und bilde das XOR mit dem Original.

## Startcode

```cpp
#include <algorithm>
#include <string>
#include <vector>
class Solution {
public:
  bool hasAlternatingBits(int n) { return False; }
};
```
