## Problem

Bir metnin tersten okunduğunda da aynı olup olmadığını kontrol eden `isPalindrome` metodunu yazın. Aynıysa `true`, değilse `false` döndürün.

## Örnekler

- `isPalindrome("kayak")` → `true`
- `isPalindrome("merhaba")` → `false`

## Kısıtlamalar

- Girdi küçük harflerden oluşan bir metindir.
- Tek karakterli metinler palindrom kabul edilir.

## İpucu

Metni ters çevirip ilk haliyle karşılaştırabilirsiniz.

## Başlangıç Kodu

```cpp
#include <string>

class Solution {
public:
  bool isPalindrome(std::string text) {
    // Çözümünüzü buraya yazın
    return false;
  }
};
```
