## Problem

Write a function named `isPalindrome` that checks whether a string reads the same forwards and backwards. Return `true` if it does, and `false` otherwise.

## Examples

- `isPalindrome("kayak")` → `true`
- `isPalindrome("merhaba")` → `false`

## Constraints

- The input contains lowercase letters.
- A one-character string is a palindrome.

## Hint

Reverse the string and compare it with the original.
