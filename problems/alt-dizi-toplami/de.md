## Problem

Addiere die Werte an geraden, nullbasierten Indizes eines Messarrays. `sumEvenIndices` soll ihre Summe zurückgeben.

## Beispiele

- `sumEvenIndices([5, 2, 7, 1, 4])` → `16`
- `sumEvenIndices([9])` → `9`

## Einschränkungen

- 0 <= nums.length <= 100000; -100000 <= nums[i] <= 100000

## Hinweis

Gehe die Indizes in Zweierschritten durch.
