## Problem

Bir ölçüm dizisinde 0 tabanlı çift indislerdeki değerleri toplayın. `sumEvenIndices` toplamı döndürmelidir.

## Örnekler

- `sumEvenIndices([5, 2, 7, 1, 4])` → `16`
- `sumEvenIndices([9])` → `9`

## Kısıtlamalar

- 0 <= nums.length <= 100000; -100000 <= nums[i] <= 100000

## İpucu

İndisleri ikişer artırarak ilerleyin.
