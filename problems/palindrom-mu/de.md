## Problem

Bestimme, ob ein Zugangscode in beide Richtungen gleich gelesen wird. `isPalindrome` unterscheidet Groß- und Kleinschreibung.

## Beispiele

- `isPalindrome("level")` → `true`
- `isPalindrome("Level")` → `false`

## Einschränkungen

- 0 <= text.length <= 100000; der Text enthält englische Buchstaben in Groß- oder Kleinschreibung.

## Hinweis

Vergleiche Zeichen von beiden Enden und bewege dich zur Mitte.

## Startcode

```cpp
#include <algorithm>
#include <string>
#include <vector>
class Solution {
public:
  bool isPalindrome(std::string text) { return False; }
};
```

        return False
