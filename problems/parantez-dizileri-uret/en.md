## Problem

Generate every balanced string that uses `n` pairs of parentheses. Return the results in lexicographic order.

## Examples

- `generateParentheses(2)` → `["(())","()()"]`
- `generateParentheses(1)` → `["()"]`

## Constraints

- 1 <= n <= 8.

## Hint

Append an opening or closing parenthesis only when the prefix remains valid.

## Starter Code

```cpp
#include <algorithm>
#include <string>
#include <vector>
class Solution {
public:
  std::vector<std::string> generateParentheses(int n) { return new String[0]; }
};
```
