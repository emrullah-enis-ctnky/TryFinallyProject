## Problem

`n` çift parantez kullanarak oluşturulabilen tüm dengeli dizileri üretin. Sonuçları sözlük sırasına göre döndürün.

## Örnekler

- `generateParentheses(2)` → `["(())","()()"]`
- `generateParentheses(1)` → `["()"]`

## Kısıtlamalar

- 1 <= n <= 8.

## İpucu

Her öneke yalnızca geçerli kalacaksa açma veya kapama parantezi ekleyin.

#include <algorithm>

#include <vector>

public:
  std::vector<std::string> generateParentheses(int n) { return {}; }
};
