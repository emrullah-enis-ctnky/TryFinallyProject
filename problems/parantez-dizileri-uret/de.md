## Problem

Erzeuge alle ausgeglichenen Zeichenfolgen mit `n` Klammerpaaren. Gib die Ergebnisse in lexikografischer Reihenfolge zurück.

## Beispiele

- `generateParentheses(2)` → `["(())","()()"]`
- `generateParentheses(1)` → `["()"]`

## Einschränkungen

- 1 <= n <= 8.

## Hinweis

Füge eine öffnende oder schließende Klammer nur hinzu, wenn das Präfix gültig bleibt.

## Startcode

```cpp
#include <algorithm>
#include <string>
#include <vector>
class Solution {
public:
  std::vector<std::string> generateParentheses(int n) { return []; }
};
```

```java
class Solution {
```

```python
        return []
```
