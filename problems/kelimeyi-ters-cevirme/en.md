## Problem

Write a function named `reverseString` that returns the given text in reverse order.

## Examples

- `reverseString("merhaba")` → `"abahrem"`
- `reverseString("kod")` → `"dok"`

## Constraints

- The input is a string.
- Return an empty string when the input is empty.

## Hint

Try reading the characters from the end of the string to the beginning.
