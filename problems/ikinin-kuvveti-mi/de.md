## Problem

Die Größe eines Speicherblocks ist `size`. Prüfe mit `isPowerOfTwo`, ob sie eine positive Zweierpotenz ist.

## Beispiele

- `isPowerOfTwo(64)` → `true`
- `isPowerOfTwo(72)` → `false`

## Einschränkungen

- `-2147483648 <= size <= 2147483647`

## Hinweis

Die Binärdarstellung einer positiven Zweierpotenz hat genau ein gesetztes Bit.

## Startcode

```cpp
class Solution {
public:
  bool isPowerOfTwo(int size) { return false; }
};
```

```java
class Solution {
  public boolean isPowerOfTwo(int size) { return false; }
```

```python
class Solution:

        return False
```
