## Problem

Bir bellek bloğunun boyutu `size` olarak verilir. Boyutun pozitif bir ikinin kuvveti olup olmadığını `isPowerOfTwo` metoduyla belirleyin.

## Örnekler

- `isPowerOfTwo(64)` → `true`
- `isPowerOfTwo(72)` → `false`

## Kısıtlamalar

- `-2147483648 <= size <= 2147483647`

## İpucu

Pozitif bir ikinin kuvvetinin ikilik yazımında yalnızca bir bit açıktır.

## Başlangıç Kodu

```cpp
class Solution {
public:
  bool isPowerOfTwo(int size) { return false; }
};
```

```java
class Solution {
  public boolean isPowerOfTwo(int size) { return false; }
}
```

```python
class Solution:
    def isPowerOfTwo(self, size):
        return False
```
