## Problem

Ein Gerät muss Protokollcodes von hinten nach vorn lesen. `reverseText` gibt den Text in umgekehrter Zeichenreihenfolge zurück.

## Beispiele

- `reverseText("north")` → `"htron"`
- `reverseText("a b")` → `"b a"`

## Einschränkungen

- 0 <= text.length <= 100000; der Text enthält ASCII-Zeichen.

## Hinweis

Erzeuge ein Ergebnis, indem du Zeichen in umgekehrter Reihenfolge anhängst.
