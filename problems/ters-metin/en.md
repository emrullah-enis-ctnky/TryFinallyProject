## Problem

A device must read log codes from end to beginning. `reverseText` returns the text with its character order reversed.

## Examples

- `reverseText("north")` → `"htron"`
- `reverseText("a b")` → `"b a"`

## Constraints

- 0 <= text.length <= 100000; text contains ASCII characters.

## Hint

Build a result by appending characters in reverse order.
